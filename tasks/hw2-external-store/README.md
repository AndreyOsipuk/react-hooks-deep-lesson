# Домашняя задача 2. Подписка на внешнее хранилище

**Тип:** найди баг, почини, напиши свой хук.

`src/cart-store.ts` - маленькое хранилище корзины вне React (так устроены Redux store, `navigator.onLine`, `localStorage`, WebSocket). ИИ-ассистент написал хук `useCartItems` на `useState` + `useEffect` - подписка есть, отписка есть.

## Часть 1

1. Запустите демо. Виджет «Подарок» кладёт подарок в корзину при появлении. Что показывает корзина?
2. Объясните **порядком выполнения**: что происходит между рендером `Cart` и подпиской в её эффекте?
3. Перепишите `useCartItems` так, чтобы тесты части 1 стали зелёными.

## Часть 2

Реализуйте `useCartSummary()`, который возвращает `{ count, last }`. Тесты части 2 должны стать зелёными.

В комментарии над хуком опишите, какие варианты вы пробовали, что пошло не так и почему.
