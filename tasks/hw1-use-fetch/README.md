# Домашняя задача 1. Ревью хука от ИИ: `useFetch`

**Тип:** найди баги, докажи тестом, почини.

ИИ-ассистент на запрос «универсальный хук для загрузки данных через fetch» выдал `src/use-fetch.ts`. В нём **минимум четыре бага**.

## Что сделать

1. Сделайте зелёными готовые тесты в `src/use-fetch.test.ts` (их не меняйте). Они ловят два бага.
2. Найдите ещё **минимум два** бага. Для каждого:
   - замените `it.todo` на тест, который **падает** на коде после шага 1;
   - убедитесь, что он падает **по нужной причине** (прочитайте сообщение об ошибке);
   - почините хук, тест стал зелёным.
3. В начале `use-fetch.ts` напишите комментарий: список всех найденных багов, по одному предложению на каждый - что увидит пользователь.

Демо (`npm run dev`) ходит в настоящий сервер «Шести городов» - откройте вкладку Network и посмотрите, сколько запросов уходит.

## Как сдать

Нажмите **Fork** (нужен вход через GitHub) и пришлите ссылку на свою копию. Без входа изменения пропадут после закрытия вкладки - тогда скачайте проект (меню проекта → Download) и пришлите архив.
