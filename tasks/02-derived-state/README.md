# Задача 2. Лишний рендер, которого не видно глазами

**Формат:** на уроке, 10 минут. **Тип:** ревью кода ИИ.

`OffersList` (`src/offers-list.tsx`) фильтрует предложения по строке поиска. На экране всё правильно, но новый линтер React (`eslint-plugin-react-hooks` 7) ругается на правило `react-hooks/set-state-in-effect`. ИИ-ассистент на вопрос «как убрать ошибку линтера» предложил отключить правило комментарием.

## Что сделать

1. Запустите демо (`npm run dev` во втором терминале), откройте консоль браузера и введите одну букву в поиск. Сколько фиксаций (commit) на одну букву? Почему?
2. Ответьте в чате: что видит пользователь **между** этими фиксациями?
3. Сделайте тесты `src/offers-list.test.tsx` зелёными, не меняя их и **не отключая правило линтера**.
