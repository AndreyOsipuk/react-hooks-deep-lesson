# Домашняя задача 3. Докажи тестом

**Тип:** проверь утверждения ИИ экспериментом.

Студент спросил ИИ-ассистента «объясни, как работают хуки» и получил пять утверждений. Некоторые из них неверны или верны только частично.

1. «После `setCount(count + 1)` переменная `count` в этом же обработчике уже увеличена».
2. «Эффект с пустым массивом зависимостей выполняется ровно один раз».
3. «Cleanup эффекта вызывается только при размонтировании компонента».
4. «Два `setState` внутри `setTimeout` вызывают два рендера: батчинг работает только в обработчиках событий».
5. «Если передать в `useState(createInitial())` тяжёлую функцию, она вызовется только при первом рендере».

## Что сделать

1. **До** написания тестов запишите в `src/claims.test.tsx` над каждым `it.todo` своё мнение: верно или нет.
2. Для каждого утверждения напишите тест, который **показывает**, как React ведёт себя на самом деле. Все тесты должны быть зелёными: тест не «падает на неверном утверждении», а фиксирует настоящее поведение.
3. Под своим первоначальным мнением допишите, совпало ли оно с тестом. Если нет - не стирайте, объясните, где ошиблись.
