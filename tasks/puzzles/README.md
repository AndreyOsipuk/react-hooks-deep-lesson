# Головоломки на хуки

Короткие примеры на функциональных компонентах. В каждом файле сверху - вопросы.

**Правило: сначала ответ, потом запуск.** Прочитайте код, напишите ответ в чат и только потом откройте пример в превью.

## Как работать

- Справа - превью. В выпадающем списке сверху выберите пример, рядом с ним указан файл с кодом.
- Внизу превью - консоль: туда попадает всё, что пример выводит через `console.log`, и предупреждения React.
- Галочка **StrictMode** оборачивает пример в `<StrictMode>`. По умолчанию она выключена.
- **Перезапустить** - смонтировать пример заново с чистой консолью.
- Код можно менять: после сохранения превью обновится само.
