# Задача 1. Снимок рендера

**Формат:** на уроке, 10 минут. **Тип:** предскажи, потом почини.

Компонент `MessageComposer` (`src/message-composer.tsx`) отправляет сообщение с задержкой 3 секунды и считает отправленные. Код написал ИИ-ассистент.

## Часть 1. Предсказание (не запускайте код!)

1. Прочитайте `src/message-composer.tsx` и три сценария в `src/answers.ts`.
2. Впишите свои ответы в `src/answers.ts` и отправьте их **в чат урока** по сигналу преподавателя.
3. Преподаватель покажет, как код ведёт себя на самом деле. Где ошиблись - сформулируйте одним предложением, **почему** код ведёт себя так.

## Часть 2. Почините

Сделайте зелёными тесты в `src/message-composer.test.tsx`, не меняя их:

- отправляется текст, который был в поле **в момент нажатия** (сейчас это уже так - не сломайте);
- счётчик учитывает **каждую** отправку, даже если таймеры пересеклись;
- если компонент размонтировали до срабатывания таймера, `onSend` не вызывается.
