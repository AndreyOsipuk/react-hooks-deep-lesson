# Задача 5. Что проверяет StrictMode

**Формат:** на уроке, 10 минут. **Тип:** найди баг, почини.

`ChatRoom` (`src/chat-room.tsx`) подключается к комнате чата и показывает входящие сообщения. `chat-server.ts` - «внешняя библиотека», её не трогаем.

## Что сделать

1. Запустите демо. Нажмите «Сервер шлёт сообщение». Сколько раз оно появилось? Нажмите «Обновить список соединений»: сколько соединений открыто?
2. Смените комнату пару раз и закройте чат. Сколько соединений осталось?
3. Ответьте в чате: ИИ-ассистент советует «уберите StrictMode, он вызывает эффекты дважды, в продакшене этого бага не будет». Прав ли он? Какой из багов останется и в продакшене?
4. Сделайте тесты `src/chat-room.test.tsx` зелёными, не меняя их.

## Вопросы для себя

- Что значит «cleanup - обратная операция к setup»? Придумайте пару примеров из «Шести городов».
- После смены комнаты старые сообщения остаются на экране. Как сбросить их **без** `setMessages([])` в эффекте?
